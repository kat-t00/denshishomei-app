# 電子署名アプリ（denshishomei-app）

介護事業所（居宅介護支援を中心に、介護事業全般）向けの、契約書・重要事項説明書を電子署名で完結できる無料ツールです。

**公開URL：** https://kat-t00.github.io/denshishomei-app/

インストール・会員登録・アップロードは一切不要。リンクを開けばすぐ使えます（お手持ちのPDFをそのままご利用ください）。

---

## このアプリの位置づけ

クラウドサイン等の汎用電子契約サービスは高機能ですが、従量課金のため利益率の薄い小規模介護事業所には導入しづらい、という課題から作られました。**無料・無保証・自己責任で使う配布ツール**という位置づけです（法人としてのサポート保証やSLAは提供していません）。

---

## 主な機能（対面署名に特化）

- お手持ちの契約書・重要事項説明書PDFに、署名欄・日付欄・氏名欄・住所欄・続柄欄・確認チェック欄をドラッグで配置し、テンプレートとして保存・再利用
- 署名欄は「利用者本人／ご家族（代理）」を事前に固定せず、**署名するその場でタップして選ぶ**方式。1つの署名欄で、本人が書ける時も、書けずにご家族が代筆する時も同じテンプレートで対応できます
- 同じテンプレートを報酬改定等で改訂した場合、版として履歴管理（過去の契約がどの版に基づくか追跡可能）
- タブレット等の同一端末で、利用者本人・ご家族（代理）が順番に署名（指・Apple Pencil・タッチペンに対応）
- 家族代理署名時は続柄・代理権限の自己申告チェックを記録
- 重要事項説明の様子を任意で録音し、音声ファイルのハッシュ値ごと証跡に記録（対応環境のみ）
- 完成した署名済みPDFには、署名者一覧・時刻・検証IDを記載した証跡ページを自動追加
- 改ざん検知用にSHA-256ハッシュ付きの監査記録(JSON)を別ファイルとして出力
- 誤って署名した契約の無効化、および再契約の記録（元のPDFは書き換えません）

## 重要な注意事項（必ずお読みください）

- **法的な効力についての保証はありません。** 本アプリは電子署名法上の推定効を意識した設計にしていますが、実際の証拠としての有効性は個別の状況によります。重要な契約については、必要に応じて専門家にご確認ください。
- **タイムスタンプは端末のシステム時計に基づくものです。** 総務省認定の時刻認証局（TSA）等、第三者機関による認定タイムスタンプではありません。
- **通信情報（IPアドレス等）は記録していません。** オフラインでも動作させるための設計判断です。
- 介護保険サービスの重要事項説明・同意を電磁的方法で行う場合、運営基準上の手続き（利用者側からの申出・承諾の取得等）は事業所側の責任で満たしてください。

---

## 動作環境

- 対応ブラウザ：Chrome / Edge / Safari などの最新ブラウザ（タブレット推奨）
- サーバー不要、外部ライブラリはすべてローカル配置。オフラインでも対面署名フローは動作します
- 署名済みPDF・監査記録（・録音した場合は音声ファイル）は自動保存されません（個人情報を含むため）。ダウンロードされたファイルはご自身で保管してください
- テンプレート（PDF書式・署名欄の位置定義。個人情報は含みません）のみ端末に自動保存されます

---

## 使い方

1. 上の公開URLをブラウザで開けば、そのまま使えます
2. 訪問先など通信が不安定な場所で使う場合は、配布用の単一HTMLファイル（`keiyaku_standalone.html`）をタブレット等にコピーし、ブラウザで直接開いてください（サーバー不要、オフラインで動作します）
